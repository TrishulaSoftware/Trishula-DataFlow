# 🌊 Trishula-DataFlow
**Sovereign Operator-Based LLM Data Preparation & Synthesis Engine**  
*Built by Trishula Software | Anti-Epeolatry Architecture*

## Overview
Re-engineered from `OpenDCAI/DataFlow` (accepted at ACM SIGMOD 2027), Trishula-DataFlow provides clean, composable operator pipelines to clean, filter, and synthesize high-lethality training datasets and RAG corpora with zero third-party wrapper dependencies.

## Key Features
- **Operator-Driven Architecture:** Decoupled cleaning, filtering, and synthesis operators.
- **Zero LiteLLM/LangChain Bloat:** Pure Python and Pydantic execution.
- **High-Velocity Ingestion:** Fast filtering and deduplication on NVMe.
